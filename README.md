# KuroSec Lab

> Security Operations × AI × Automation

KuroSec Lab is a personal security lab focused on learning, building,
and documenting practical security operations.

SOC構築・セキュリティ運用を中心に、実際に手を動かしながら
得た知識、設計、検証結果、ツールなどを公開しています。

---

## 🎯 Mission

「セキュリティを、実際に運用できる形にする。」

KuroSec Labでは、単なる知識の整理ではなく、

- どう設計するか
- どう実装するか
- どう運用するか
- どこで失敗するか
- どう改善するか

までを実践・記録します。
